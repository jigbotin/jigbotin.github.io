   - In MetaTrader 5, click **File → Open Data Folder**.

   - In the MT5 Navigator panel (Ctrl+N), right-click **Expert Advisors** and click **Refresh**.
3. **Attach to Chart:**

   - Drag **Jig Bot** onto the chart.
   - In EA Inputs (F7), enter your License Key in `InpLicenseKey`.
